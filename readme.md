
# Where have I landed?

You have landed on the repository for my toy project, Networker!

Networker is a reimplementation of many networking protocols, made while learning about how networking works!

  

# Well, what protocols are implemented then?

Only the TFTP protocol is implemented currently; the implementation is not perfect. It can, currently, act as a server for a transfer. The only references for the implementation of TFTP was the [RFC](https://datatracker.ietf.org/doc/html/rfc1350).

# Well, what's next then?
My next goal is to write a better version of TFTP, making a small and powerful coroutine library alongside it.
